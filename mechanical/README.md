# 3D Model and Mechanical Design

The initial 3D model used for this project was created by **theZaX** and obtained from Thingiverse.

- **Original model:** https://www.thingiverse.com/thing:3039476
- **Original author:** theZaX
- **License:** Creative Commons Attribution (CC BY)

The model is used as a reference for the mechanical design and 3D-printed components of the STM32 Desktop Robotic Manipulator project.

Any modifications made to the original model will be documented separately. The original work remains attributed to its creator.
